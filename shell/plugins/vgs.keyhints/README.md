# Key Hints

Key Hints shows every shortcut VGS adds in one window and lets you change its keys there. It is for anyone who wants to see or change a shortcut without opening each plugin's page.

![The Key Hints window](../../../docs/images/plugins/vgs.keyhints-window.webp)

## Features

- Opens with `SUPER+/` on the focused monitor and fits on it.
- Lists the shortcuts of every plugin that is on, grouped by plugin.
- Finds a shortcut as you type, by its plugin, what it does or its keys.
- Changes a shortcut when you select its field and press the new keys. The keyboard button lets you type the keys instead.
- Saves a change at once. The plugin's Settings page shows the same keys.
- Removes a shortcut's keys and keeps the row, so you can set new ones.
- Names each other plugin shortcut and each of your own Hyprland binds that uses the same keys.
- Closes with Escape, `SUPER+/` or your close key.
