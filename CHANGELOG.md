# Changelog

## Unreleased

- Jarvis has a second cloud voice, Gemini Live from Google. Choose Gemini under Settings > Jarvis > Voice provider and store a Gemini key with Add key: Google hears you and speaks the reply, and the AI model you chose still answers. Voice offers Gemini's 30 voices, with Preview. The Realtime key setting is now Voice key, and offers the keys of the chosen cloud voice. Always talk mode still needs the local voice.
- The Jarvis bar tooltip, its Mute not saved notice and its stopped notice after a failed start say what happened and what to do. Before, each also showed an internal code, such as jarvis: hello=timeout. The Jarvis memory row no longer starts with jarvis: memory=sqlite. The code stays in the log and on the Daemon row.
- Settings > Jarvis > Voice provider shows one line of help. Its info button explains Realtime and Auto.
- On the Jarvis page under Setup, the Voice step reads Timed out with what to do when local voice does not get ready in time, and the Setup row after a failed start shows what happened and what to do. Before, each also showed an internal code, such as SPEECH=LOCAL-READY-TIMEOUT or JARVIS: HELLO=TIMEOUT. The code stays in the log and on the Daemon row.
- Jarvis uses the local voice by default: speech stays on your computer and replies start sooner. Realtime stays a choice under Settings > Jarvis > Voice provider, as the slower cloud voice, and Auto keeps its meaning. A Voice provider you already chose stays. Before, the default was Auto, which used Realtime whenever an OpenAI key was stored.
- Agent Warden, AI Usage, Passwordless sudo and Jarvis draw their bar icon in the theme's own colour for each state, as Updates and Cloud Sync do: a warning is one amber on every widget. Before, these four drew a paler or darker shade of that colour.
- In the notifications panel's header, Sound off shows its icon in a round accent box, as Do Not Disturb on and an open History do. Before, Sound off changed only its icon, and the box was square inside the round header. A screen reader names each icon's state: Notification sound on or off, Do Not Disturb on or off, History open or closed.
- Jarvis calls the session that runs your agent fleet your Jarvis session: in the confirmation before a fleet request, the Agent fleet row under Setup, its setup window and the Jarvis README. Before, it called it the master session.
- A button that offers to install a missing command shows the install notice on every press. Before, a press within 10 minutes of Not now showed nothing, in Agent Warden, Bluetooth, Sound, Network, Capture, Clipboard and VPN. VPN's Import WireGuard opens the import once the install ends. A plugin raises an offer with no press through `shell.requirements.suggest`, which still waits 10 minutes after Not now.
- On a small screen such as 1366x768, a floating terminal window, such as btop from System Monitor's See all, shows its whole border. Before, its top edge lay under the bar and its bottom edge past the screen.
- A click on the Voice mic in the bar starts dictation, and a second click stops it, as the dictation key does. Without voxtype, a click offers to install it, then opens Set up. Before, a click opened voxtype's Configure screen. Configure is now Voxtype Settings in the mic's right-click menu.
- The Jarvis page has two new settings under AI model: Model and Effort. They list the models of the app you chose as the AI model, read from that app while the page is open: Claude Code, Codex, GitHub Copilot or Pi. Effort lists the levels a Claude Code, Codex or Pi model takes; GitHub Copilot sets its own. When you choose an app, Jarvis saves Fable 5.1 at high effort where the app offers it, else Opus 5.5 at high effort, else the app's own model and effort. Your choice is saved and reaches the app. A Pi setup is one AI model choice, with its models under Model. For a Pi setup, Jarvis saves Pi's own model and that model's own effort. An Anthropic API key shows both, with Opus 5.5 at high effort by default; other API keys and a local server show neither setting.
- Jarvis with an Anthropic API key runs Claude Opus 5.5 at high effort. Before, it ran Claude Haiku 4.5.
- A plugin's `optionsFrom` setting may declare `hideEmpty: true`: the Settings page then draws no field while nothing is offered for it.
- A plugin can read `shell.status.viewed`: it is true while the Settings window shows that plugin's page.
- Jarvis's Voice provider has a new first choice, Auto, which is the default: Realtime when an OpenAI key is stored, else Local. Storing or removing the key changes the voice with no restart, and a choice of Local or Realtime stays. With no key the Jarvis page asks for none; the OpenAI key row under Details > Voice offers Add key.
- Jarvis on GitHub Copilot can use its tools: it reads skills with Help and lists, reads and changes files through Jarvis's own file tools, which ask you before a delete as with the other AI models. Before, Copilot got none of Jarvis's tools, and a file tool call ended the conversation.
- Jarvis's cloud voice is OpenAI's Realtime voice, which replaces the earlier cloud voice. Settings > Voice > Voice provider offers Local and Realtime, and Realtime key names the OpenAI key it uses. OpenAI hears you and speaks; the AI model you chose answers each request, and the voice reads its reply aloud word for word.
- Settings > Appearance has a new Sounds page. It lists the sounds of each enabled plugin: a new notification, the dictation tones and Jarvis's feedback tones. A notification has a list of sounds with Off first, and Test plays the chosen sound; it plays no sound until you choose one. The dictation tones and the Jarvis tones are each On or Off.
- Dictation sounds on the Sounds page turns voxtype's own tones on or off: VGS changes the setting in your voxtype config and restarts voxtype. The page shows the value your voxtype config holds, so a change you make in voxtype's Configure screen shows there too.
- Jarvis's Feedback sounds switch moves from the Jarvis page to the Sounds page.
- A plugin declares its sound events in the new manifest key `sounds` and plays one with `shell.sounds.play` through capability `sounds`. An event whose value another program holds is `held`: the plugin states the value and applies the page's choice with `shell.sounds.hold` and `shell.sounds.report`. Capability `soundSettings` lists every event and writes the choices, shell.json `sounds`. `pw-play` is a core requirement.
- The Fonts page's Terminal list holds only fixed-width fonts that draw letters, digits and punctuation, which fontconfig lists, so icon and emoji fonts stay out of it. Both lists show each family once, with no entry for a style such as Light, and a font you set stays in its list. The Fonts plugin needs `fc-list`, and the Arch, Fedora and nix packages and the installer add fontconfig.
- Settings > Appearance has three new pages. Motion turns animations on or off and sets their style, Smooth or Snappy, and their speed, for the shell and, with Window animations on, for your windows. Windows sets the corner radius of windows, flyouts and grouped window tabs, and the window border width. UI sets the corner radius of buttons, text fields and segmented controls. Each value shows Set by theme until you change it, and Use theme value puts the theme's value back. The values live in shell.json `appearance`, which the new capability `appearance` writes. With no value set, every theme draws as before.
- Settings > Appearance has a Fonts page. Interface sets the font of the shell's text: body text, headings, labels, buttons and the bar; code and key names keep the theme's fixed-width font, and the launcher and notifications keep their own. Terminal sets the font of Kitty and Ghostty through the theme files VGS writes for them, so it applies while a theme is applied. Each shows Set by theme until you choose a font. With no font set, the shell and both terminal files are as before. The token table adds `font.family.caps`, the family of labels, buttons and the bar, which follows `font.family.mono` unless a theme sets it. `vgshell theme follow` applies the theme again when the terminal font changes.
- The Themes plugin's Apply theme borders, Apply theme corners and Apply theme animations switches are removed. Their off state is Use my Hyprland value on the Windows page, and window animations are the Motion page's Window animations switch, off by default.
- `qs.Ui` adds `ValueSourceRow`, the one row for a value that maps to a Hyprland option: it says whether the theme, you or your Hyprland config sets the value and offers the way back. Mouse uses it. `SavedSlider` is the slider those pages save on release.
- Mouse settings show the value Hyprland applies for a setting VGS does not set. After Use my Hyprland value, Pointer speed reads your config's value, not 0.00×. The `hyprland` capability adds `values`, Hyprland's own value of each of a plugin's options the layer does not write.
- The theme browser opens on `SUPER+SHIFT+T` and the wallpaper browser on `SUPER+SHIFT+W`. `SUPER+CTRL+T` and `SUPER+CTRL+W` no longer open them.
- The theme browser's selected card shows a screenshot of the theme on a desktop, which every bundled and catalog theme ships as `preview.jpg`, in place of the desktop it drew from the theme's colours. An installed catalog theme keeps its catalog screenshot. A theme without one shows its first wallpaper, else its background and name. `vgshell theme preview` is removed.
- A dropdown's title switch that controls less than the title names shows what it controls in a small dim label at its left: "Wi-Fi" in Network, "Tailscale" in VPN. Bluetooth's switch shows no label.
- The VGS logo is a new drawing: the letters in solid blocks with a shaded shadow. Floating terminals draw it in the theme accent.
- The bundled `light` theme is removed; `vgs` is the one bundled theme. The light themes are in the theme catalog, such as `flexoki-light`, which the theme browser installs.
- New plugin Clipboard, `vgs.clipboard`: a history of the last 500 text and image copies. `SUPER+CTRL+V` opens it. Typing filters the entries, Enter pastes the selected entry into the application that had the keyboard, and Ctrl+P pins an entry. A copy that a password manager marks as secret is never recorded. The plugin is on by default and saves the history to disk; Shift+Delete in the history clears it.
- A TUI's `requires` may be an empty list: the script needs none of the plugin's requirements, so a missing command never holds it back. Automations' run transcript and Updates' Update one source declare it.
- Voice and Web Apps are on after an update that brings them, as every new plugin is: Voice's mic shows in the bar. A plugin you turned off stays off.
- A shortcut with more than one key shows them in one row in Settings and Key Hints, each key apart with "or" between them, such as Right Alt or Right Ctrl. Left and Right pick a key, Delete or the remove button takes it out, and the add button listens for another.
- Set up in Voice settings on a system without voxtype offers to install it, then runs the rest of the setup. Any plugin's setup screen that a missing command held back opens once the requirement notice installs that command; Not now cancels it.
- `ListItem` of `qs.Ui` draws its text and its secondary line as plain text. A tag in a row's text is drawn as text, never as markup.
- The Arch and Fedora packages install the browser theme writer and its sudoers rule, so Chromium, Chrome, Edge and Brave follow the theme for every user with no setup step. A home install keeps the one-time Install browser theming step. The Settings window checks the system again each time it opens, so the Browser theming row shows a setup run from a terminal while the shell ran.
- System → Displays can set a display's resolution, refresh rate, scale and orientation. A guarded trial applies the change first, and Keep saves it into the generated Hyprland layer.
- `qs.Ui` adds `FormRow`, the one key/value row that `Field` and the Settings page now draw with, with an optional message line under its control; `DeviceRow`, a list row for any device with a battery or level badge, actions and an overflow menu; and `LevelOsd`, the card of a volume or brightness display. New `osd` and `deviceRow` theme tokens size the display and set the battery thresholds.
- Slack photos and AI Gateway credits have visible Settings switches and masked connection fields. Slack setup supplies the app text and opens Slack Apps. AI Gateway setup opens Vercel to create a key. Both features are off by default. The manifest `extras` key and its hidden-feature filter are removed.
- Jarvis adds Talk, Mute and Stop keys, hold or toggle mode, and persistent privacy mute. Key tests use a private scripted engine. The installed daemon remains unconfigured and captures no audio.
- Menus and select lists fill their rows to the border: a hover or selected row meets the list's top and side edges, the row insets its own text, and the scroll bar draws over a strip each row keeps clear. The `menu.padding` token is removed, and a theme that sets it is refused; `menu.item.radius` now follows `menu.radius`.
- Settings Status and Requirements rows are divided into groups: 4 px between a row's own lines, 12 px and a faint hairline between rows, from the new `groupList` tokens and the `GroupList` component.
- A key/value label and its value read as one pair: labels, section headings, buttons, badges and key caps draw at 12 px, a read-only value draws in the new 13 px `text.value` role, and the label column is 140 px wide.
- Jarvis adds one-click local voice setup with pinned Python packages, model verification and a real bundled-clip probe. Failed setup clears readiness. Settings rechecks after the setup terminal closes.

- Jarvis adds bounded account discovery, user-added directories, existing keyring references and a floating Accounts terminal. Settings offers discovered brain accounts. Explicit API and local Verify use the outbound door for one small inference request. Login hints never mean Verified. Subscription and speech-only handoffs remain unavailable.
- Jarvis adds a masked Add key floating terminal, libsecret storage and metadata-only key presence in Settings. Provider keys stay out of files, command arguments, logs and status. The reference API supports future provider adapters and the accounts picker.
- Settings schema strings must declare `presets` or `optionsFrom`. Plugin authors replace free text with presets, and use `allowCustom` when users can still type a fitting value. `Field.compact` and the `row.compactHeight` theme token are removed; plugins and themes use the single inline row height.
